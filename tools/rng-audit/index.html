Порог значимости α = 0,01 после поправки Холма на число тестов. p-value показывает, насколько вероятен такой результат у честного генератора; маленькое значение означает подозрительное отклонение. При 8 тестах честный ГСЧ иногда даёт одиночное p < 0,05, это нормально.

Проверка «угадывания следующего»

Каждая стратегия делает прогноз на каждый спин, видя только предыдущие выпадения, а мы считаем попадания. У честного генератора любая стратегия попадает около 2,78% (1 из 36). Стратегия «по последним 5 числам» отдельно не проверяется: одна и та же пятёрка повторяется примерно раз в 60 466 176 спинов, учиться ей не на чем. Её зависимость ловят порядки 1–2 и автокорреляция.

Частоты выпадений

Линия показывает ожидаемую частоту, полоса — коридор ±2σ. У честного генератора примерно 1–3 числа из 36 выходят за полосу просто случайно. Красным выделены числа за пределами ±3σ.

Сколько нужно данных

С ручным вводом реально набрать сотни спинов. Этого хватает, чтобы поймать грубые ошибки: зацикливание, залипание числа, сильный перекос. Перекос вероятности в 10% (2,78% → 3,06%) для одного числа требует десятков тысяч спинов. Для такой точности выгружайте логи с сервера и вставляйте их списком.
